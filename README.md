# DVTapeMerger

同じ miniDV テープを複数回キャプチャしたファイル（WinDV の `.avi`、iMovie の `.dv` など、撮影カットごとに分割されたもの）から、
フレーム単位・ブロック単位で良好なデータを選び、**1本の動画ファイル**にまとめる Windows 用ツールです。

フレームの結合処理そのものには [dvrescue](https://github.com/mipops/dvrescue) のコマンドライン版を外部ツールとして使います。
このツールは、大量の分割ファイルの対応付け・dvrescue の一括実行・結果の連結・エラーの可視化を受け持ちます。

## 主な機能

- キャプチャファイル（`.dv` / `.avi` / `.dif`）をフォルダーごと追加
- 各ファイルの DV ストリームからタイムコード・撮影日時・ブロックエラーを読み取り
- タイムコードと撮影日時の範囲が重なるファイルを自動で「グループ」にまとめる
  （キャプチャごとに分割位置が違っていても、同じ区間を含むファイル同士が組み合わされます）
- グループごとに `dvrescue --merge` を実行し、良いフレーム・ブロックを採用
- 結果を撮影順に連結して 1 本で出力（`.dv` / `.avi` (Type-2) / `.mov` / `.mkv`）
- 入力ごと・結合後のエラー分布をグラフ表示、レポート（`report.txt`）とシーン一覧（`scenes.csv`）を保存

## メタ情報について

DV では撮影日時・タイムコード・カメラ情報などは各フレームの DIF データ内に記録されています。
本ツールはどの出力形式でも DIF フレームを一切再エンコード・改変しないため、これらの情報はそのまま残ります
（`.mov` / `.mkv` / `.avi` から取り出した映像データが `.dv` 出力とバイト単位で一致することを確認済み）。

加えて、コンテナ形式では次の情報を付けます。

| 出力形式 | 作成日時 (creation_time) | 開始タイムコード | チャプター（撮影開始ごと） |
| --- | --- | --- | --- |
| `.dv`  | （DIF内のみ） | （DIF内のみ） | — （`scenes.csv` に出力） |
| `.mov` | ○ | ○ (tmcd) | ○ |
| `.mkv` | ○ | ○ (タグ) | ○ |
| `.avi` | — | — | — |

## 必要なもの

- Windows 10 / 11（x64）
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（ビルドする場合は .NET 10 SDK）
- **dvrescue CLI**（Windows 版）: <https://mediaarea.net/DVRescue> からダウンロード
- **FFmpeg**: AVI ファイルの読み込みと、`.dv` 以外での出力に必要（`ffmpeg.exe` に PATH が通っていれば自動検出）

dvrescue と FFmpeg は本リポジトリには含まれていません。[ツール] → [設定] で場所を指定するか、
`DVTapeMerger.exe` と同じフォルダーに置いてください。

## ビルド

```
cd src
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o ..\publish
```

## 使い方

1. [フォルダーを追加...] で、同じテープのキャプチャファイルをすべて追加します（複数回分のキャプチャを混ぜて追加して構いません）。
2. [解析] を押すと、各ファイルのフレーム数・タイムコード・エラー率が表示され、結合グループが作られます。
   グループを選ぶと、入力ごと・結合後のエラー分布がグラフで表示されます。
3. 出力ファイルと形式を選び、[結合を実行] を押します。

コマンドラインでも実行できます。

```
DVTapeMerger.exe --cli [--dvrescue path] [--ffmpeg path] [--work dir] [--no-logs] [--analyze] -o output.mkv 入力フォルダーまたはファイル...
```

## 処理の流れと注意点

- **AVI**: dvrescue の結合処理は入力を生の DV ストリームとして読むため、AVI は FFmpeg のストリームコピーで
  DV ストリームを取り出してから使います（無劣化。取り出したデータは作業フォルダーにキャッシュされ、終了時に削除されます）。
  作業フォルダーには、AVI の合計サイズと同程度の空き容量が必要です。
- **グループ分け**: タイムコードが逆戻りする箇所や大きく飛ぶ箇所ではファイル内でも区間を分け、
  タイムコード範囲と撮影日時範囲がともに重なる区間同士を同じグループにします。グループは撮影日時順に連結されます。
- タイムコードが記録されていない区間は、他のキャプチャと対応付けできないため単独で出力されます。
- どのキャプチャでも同じ場所が壊れている場合は修復できません（結合は「良い方を選ぶ」処理です）。
- エラー率は、映像 DIF ブロックのうち STA（エラー状態）が 0 以外のものの割合です。
